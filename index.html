Preguntas frecuentes

¿Cuándo sale la 1.20.1?

Todavía no tengo una fecha exacta. Desarrollo Skell yo solo y, además de portar esta versión, tengo que atender errores, optimizar el cliente y agregar módulos nuevos. Aun así, calculo que estará disponible en unas horas.

¿Cómo lo instalo?

Instala Fabric Loader para tu versión, pon el .jar de Skell y Fabric API en .minecraft/mods y abre el launcher con el perfil de Fabric.

¿Qué necesito?

Para 1.21.11: Fabric Loader 0.18.1 o superior, Fabric API y Java 21. Para 1.20.1: Fabric Loader, Fabric API y Java 17. El launcher oficial de Minecraft ya incluye el Java correcto.

¿Cómo abro el menú?

Dentro del juego, pulsa Shift derecho. Puedes cambiar la tecla en Opciones › Controles.

¿Por qué mi antivirus lo marca?

Algunos analizadores avisan porque uso PowerShell para mostrar la música que suena en Windows y porque el cliente incluye enlaces a mi web y a Discord. Es un aviso genérico por esas funciones.
